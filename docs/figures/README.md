# ETPS figures

The SVG charts below are deterministic illustrative calculations. They are not experimental observations. The Schwarzschild chart assumes a static observer outside an ideal non-rotating spherical mass. The entropy-proxy chart is deliberately labeled as a toy curve.

- `time_dilation.svg`: proper-time ratio against speed β=v/c.
- `schwarzschild_clock_rate.svg`: static clock rate against r/rₛ.
- `mass_energy.svg`: rest energy from E₀=mc².
- `entropy_proxy_toy.svg`: illustrative logistic curve with no claim of physical entropy dynamics.
