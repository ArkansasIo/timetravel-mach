# Project structure

- `time`: legacy ETPS manuscript; retained without overwriting.
- `etps/`: Python package, scientific toy models, catalog, CLI.
- `tests/`: unit tests for numeric domains and limiting behavior.
- `docs/`: thesis outline, equation audit, evidence rules, research roadmap.
- `data/`: constants and machine-readable catalog data.
- `database/`: MySQL schema and seed data.
- `examples/`: reproducible calculations, CSV sample, plot generation.
- `wolfram/`: symbolic/numeric query templates.
- `.github/workflows/`: automated test workflow.
