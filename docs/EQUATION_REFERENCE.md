# Equation reference and variable conventions

## Special relativity
- Lorentz factor: γ = 1/√(1−β²), where β=v/c and |β|<1.
- Inertial proper time: Δτ=Δt/γ for constant speed in flat spacetime.
- Relativistic energy-momentum: E²=(pc)²+(mc²)².
- Rest energy: E₀=mc².

## General relativity
- Einstein field equation: Gμν+Λgμν=(8πG/c⁴)Tμν.
- Schwarzschild radius: r_s=2GM/c².
- Static Schwarzschild clock ratio: dτ/dt=√(1−r_s/r), for r>r_s and a static observer in the exterior geometry.
- Proper time with signature (−,+,+,+): c²dτ²=−gμνdxμdxν along a timelike path.

## Quantum information
- Density operator: ρ=ρ†, ρ⪰0, Tr(ρ)=1.
- Purity: P=Tr(ρ²), with 1/d≤P≤1 for a d-dimensional state.
- Von Neumann entropy: S=−Tr(ρ ln ρ); dimensionless when using natural logarithms.
- Unitary evolution: ρ(t)=U(t)ρ(0)U†(t), for a closed system and unitary U.

## Cosmology
For a spatially homogeneous and isotropic FLRW spacetime, the scale factor a(t) describes expansion. For radial null paths in cosmic time and comoving radial coordinate χ, dχ/dt=±c/a(t). The exact interpretation depends on coordinate normalization and cosmological model.

## Dimensional checks
- [c]=m·s⁻¹; [G]=m³·kg⁻¹·s⁻²; [ℏ]=J·s.
- Every additive term in an equation must have matching dimensions.
- Never assign numerical values without units and stated constants.

## Caveat
The expression ΔEΔt≳ℏ/2 is not a context-free universal theorem identical to position-momentum uncertainty. State the operational definition and assumptions whenever discussing energy-time relations.
