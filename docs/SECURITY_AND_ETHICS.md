# Research integrity, security, and ethics

- Do not describe hypothetical scenarios as verified experimental findings.
- Preserve the legacy manuscript and use audited replacement files rather than silently rewriting source claims.
- Do not fabricate publications, DOI numbers, measurements, or quotations.
- Use parameter validation and reproducible tests for numerical code.
- Do not store credentials, access tokens, or private personal data in source control.
- Any future web ingestion must respect source licenses and copyright, keep provenance metadata, and avoid copying restricted full texts.
- Review code dependencies and pin versions for release builds.
