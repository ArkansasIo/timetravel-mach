## Core equations
Proper time along a timelike worldline:
`dτ² = -(1/c²) gμν dxμ dxν` for metric signature (-,+,+,+), with coordinates expressed consistently.
Schwarzschild exterior static clock:
`dτ/dt = sqrt(1 - 2GM/(rc²))`.
FLRW radial null path:
`dχ/dt = ±c/a(t)` when the FLRW metric is written with cosmic time and comoving radial coordinate χ.

These formulas require the stated metric conventions and assumptions. No section should claim a practical time machine without evidence.
