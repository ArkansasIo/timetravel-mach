# ETPS research file checklist

For each system, the following fields are required before the record is considered research-complete:

- [ ] Research question and scope
- [ ] Evidence status and justification
- [ ] Notation, units, and coordinate conventions
- [ ] Equations with derivation and source
- [ ] Assumptions, initial and boundary conditions
- [ ] Domain of validity and limiting-case checks
- [ ] Peer-reviewed or primary references verified
- [ ] Reproducible code and pinned dependencies where practical
- [ ] Unit tests and expected output
- [ ] Data provenance and uncertainty
- [ ] Plots labeled as simulation or observation
- [ ] Counterexamples, falsifiability, and limitations
- [ ] Review status and change log

A generated template is not equivalent to a completed research paper. Use this checklist to track completion honestly.
