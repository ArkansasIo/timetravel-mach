# Contributing to ETPS

1. Preserve the legacy `time` manuscript unless a change is explicitly documented.
2. Add new research content as a separate file and cite trustworthy sources.
3. Mark each claim ESTABLISHED, ACTIVE_RESEARCH, TOY_MODEL, SPECULATIVE, or FICTION.
4. Include units, variable definitions, assumptions, and domains for every equation.
5. Add tests for numerical code and include limiting-case checks.
6. Label plots as measurements, calculations, or synthetic simulations.
7. Do not fabricate citations or imply that Wolfram|Alpha output validates a physical hypothesis.
8. Run `python -m unittest discover -s tests -v` before submitting.
