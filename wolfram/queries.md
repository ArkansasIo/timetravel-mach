# Wolfram|Alpha query templates

Use these as calculation prompts, not as sources of scientific validation.

- Lorentz factor: `gamma = 1/sqrt(1-(0.8)^2)`
- Proper time for constant speed: `10 seconds / (1/sqrt(1-(0.8)^2))`
- Schwarzschild radius: `2*G*M/c^2`
- Static Schwarzschild clock ratio: `sqrt(1-2*G*M/(r*c^2))` with explicit SI values and r greater than Schwarzschild radius.
- Rest energy: `E=m*c^2` for m=1 kg.
- Density-matrix purity: `trace(rho^2)` for a fully specified matrix.
- Von Neumann entropy: `-trace(rho*log(rho))` with stated logarithm base.
- FLRW radial null equation: integrate `c/a(t)` for a specified scale factor.

Always record the exact query, assumptions, units, result, and date. A symbolic algebra engine can simplify a model but cannot establish that the model describes nature.
