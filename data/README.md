# Data folder

- `systems.csv` / `systems.json`: compact hand-curated catalog entries.
- `scenario_catalog.json`: scenario ideas and their evidence labels.
- `constants.json`: reference constants with SI units.

The catalog is intentionally curated, not a complete database of all possible temporal theories. Expand records only with clear provenance and status labels. Synthetic data and simulated outputs must never be represented as observational measurements.
